# Doodle Shield

Cute draw-a-shape physics puzzle (YouTube Playables build).

- Game: `youtube-playables/index.html` (single file, no dependencies). Vercel serves this folder (see `vercel.json`).
- Upload bundle: `youtube-playables/doodle-shield-playables.zip` (`index.html` at the ZIP root).

## What's in the game

- Draw lines with a finger or mouse; they fall into place and fade. Block rolling, falling, bouncing, splitting and homing attackers until the timer ends.
- Levels get steadily harder, with random twists (swarm, heavy rollers, storm, crossfire, sky dive) and a boss fight every 10th level.
- Tap floating bubbles for power-ups: slow motion, free ink, shield.
- Earn stars to unlock hats; daily streak and best level are saved with the Playables save API.
- Full-screen scenery on phone, tablet and desktop; text in English, Russian, Spanish, Portuguese, German, French and Turkish.
